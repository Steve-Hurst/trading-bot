# Trading Strategy Backtester

## Description & Purpose
A Python backtesting engine built to simulate momentum trading strategies using local historical stock market arrays.

## AI Tools & Environments Required
- **Required Stack**: Python 3.x, NumPy, Pandas
- **Troubleshooting**: Verify that pandas and numpy are installed using 'pip install -r requirements.txt'.
- **AI Integration Notes**: Provides an advanced mock framework for testing financial portfolio allocation algorithms.
